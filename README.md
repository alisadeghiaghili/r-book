# کتاب R — مقدماتی

منبع فارسی آموزش زبان برنامه‌نویسی R برای سطح مقدماتی.

- متن کتاب **راست‌به‌چپ** است.
- کدها و خروجی‌ها **چپ‌به‌چپ** و در بلوک‌های code نمایش داده می‌شوند.
- خروجی کدهای تک‌خطی بلافاصله بعد از همان خط آمده است؛ برای مسائل چندخطی ابتدا کد کامل، سپس نتیجه.

## فهرست

1. [متن کامل کتاب](book.md)
2. فایل Word/PDF در پوشه [`exports/`](exports/) (در صورت وجود)

## چگونه بخوانم

در GitHub، `book.md` را باز کنید. جهت صفحه با `dir="rtl"` روی ریشهٔ سند تنظیم شده است.

اگر از VS Code یا preview محلی استفاده می‌کنید، برای نمایش بهتر فارسی می‌توانید از افزونهٔ Markdown Preview Directional یا تنظیم `dir` در پوستهٔ سفارشی استفاده کنید.

## اجرا

برای اجرای نمونه‌ها به [R](https://cran.r-project.org/) و پیشنهاداً [RStudio / Posit](https://posit.co/downloads/) نیاز دارید. برخی بخش‌ها به پکیج‌های `dplyr`، `readr`، `readxl`، `tibble` وابسته‌اند.

```r
install.packages(c("dplyr", "readr", "readxl", "tibble"))
```
